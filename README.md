## Instalação

### Clonar o projeto

    git clone https://github.com/fahadkalil/Introducing_the_World_App.git    

### Para executar (Windows / Linux / MacOS)

- No terminal
  1) Acessar a pasta do projeto:

          cd Introducing_the_World_App

  2) Criar um servidor http com Python:

          python -m http.server -b 127.0.0.1 8000

  3) Acessar via navegador:  [http://127.0.0.1:8000](http://127.0.0.1:8000)

### Para atualizar com novas modificações do repositório (na pasta do projeto)

    git pull
